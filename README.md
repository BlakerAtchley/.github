# .github

Default community health files for every repository owned by [BlakerAtchley](https://github.com/BlakerAtchley).

Any repository that does not have its own copy of these files uses the versions here:

- [Code of Conduct](CODE_OF_CONDUCT.md)
- [Contributing Guide](CONTRIBUTING.md)
- [Security Policy](SECURITY.md)
- [Issue templates](.github/ISSUE_TEMPLATE)
- [Pull request template](.github/pull_request_template.md)

Each repository keeps its own `LICENSE`, because GitHub does not support a shared default license.
